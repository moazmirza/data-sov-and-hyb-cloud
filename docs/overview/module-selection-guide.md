# Module Selection Guide

Choose the smallest module that answers the governance question you are trying to solve.

| Module | Best For | Key Dependency | Recommended First Step |
|---|---|---|---|
| 0 Foundation | Shared platform setup | None | Read `README.md` in Module 0 |
| 1 Resource Tagging | Required metadata hygiene and coverage | Shared Fabric model | Review module dependencies |
| 2 Data Residency | Geography and sovereignty analysis | Purview plus Fabric | Confirm glossary and residency sources |
| 3 Confidential Computing | High-sensitivity workload investigation and action | Power Platform plus Copilot Studio | Review action guardrails |
| 4 Defender Enablement | Security posture reporting | Shared Fabric model | Confirm Defender data feeds |
| 5 OS Patching Enablement | Patch reporting and readiness visibility | Shared Fabric model | Review input source coverage |

If you are unsure, start with Module 0 and Module 1 before adopting action-enabled modules.
