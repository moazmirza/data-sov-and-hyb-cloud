# Repo Navigation

## Start Here If You Are New

1. Read `README.md`.
2. Read `docs/overview/what-this-solution-is.md`.
3. Read `docs/overview/architecture-overview.md`.
4. Read `docs/overview/module-selection-guide.md`.

## Start Here If You Want One Scenario

1. Open the chosen module folder in `modules/`.
2. Read that module's `README.md`.
3. Check `dependencies.md`.
4. Complete `prepare.md`, then `build.md`, then `test.md`.

## Start Here If You Want The Full Solution

1. Complete `modules/module-0-foundation/`.
2. Implement Modules 1 through 5 in order.
3. Use `shared/` for reusable technical assets and `releases/` for packaging.
