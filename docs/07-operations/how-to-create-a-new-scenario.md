# How to Create a New Scenario

## 1. Define the compliance question

Describe the policy, control, or risk question this scenario answers.

## 2. Identify source data

List data sources, fields, and update cadence.

## 3. Create scoring logic

Document scoring rules and output schema in `docs/06-data-model/scoring-logic.md`.

## 4. Publish to semantic model

Map scenario outputs to facts, dimensions, and measures.

## 5. Add report experience

Add visuals and explain user interpretation.

## 6. Add agent read path

Document user prompts, tool usage, and expected responses.

## 7. Add optional preview/apply action

If remediation is supported, implement guardrails and confirmation patterns.
