# Naming Conventions

Use clear, stable names that indicate module, purpose, and deployment scope.

## Recommended Pattern

`<solution>-<module>-<purpose>-<environment>`

Examples:
- `dghf-tagging-score-dev`
- `dghf-residency-preview-test`
- `dghf-cc-investigate-prod`

Avoid names tied to dates, experiments, or personal workstreams.
