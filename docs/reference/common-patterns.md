# Common Patterns

## Recommended Repo Pattern

Use `modules/` for reader guidance and `shared/` for implementation storage.

## Recommended Delivery Pattern

1. Prepare shared foundation.
2. Implement a single module.
3. Validate end-to-end behavior.
4. Expand to additional modules.

## Recommended Action Pattern

For write operations, prefer a preview then apply flow with confirmation, logging, and explicit permissions.
