# Shared Implementation Assets

This folder stores reusable implementation assets by technical type.

Use `solution-modules/` for the primary reader journey.
Use `shared/` when a module instructs you to deploy, import, configure, or validate a concrete implementation asset.

## How to Use This Folder

1. Start from the relevant module README under `solution-modules/`.
2. Follow the module's Build Instructions.
3. Pull the exact implementation artifacts from the folder listed below.

## Folder Map

| Folder | Purpose |
|---|---|
| `azure-policies/` | Policy and initiative artifacts for governance/tagging/sovereignty controls |
| `fabric/` | Fabric notebooks, lineage docs, and reproducibility assets |
| `functions/` | Azure Functions implementation assets and function-level docs |
| `infra/` | Shared infrastructure artifacts (platform and Arc evidence) |
| `power-platform/` | Copilot agent topics, custom connectors, and flows |
| `reports/` | Power BI report assets |
| `semantic-model/` | Fabric/Power BI semantic model assets |
| `templates/` | Sanitized environment/config templates |
