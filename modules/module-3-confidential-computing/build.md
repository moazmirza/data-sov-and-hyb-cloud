# Build

## Implementation Steps

1. Configure confidential-compute related policy or classification signals.
2. Load investigation and scoring logic into shared pipelines and semantic model assets.
3. Deploy function assets that support investigation and preview or apply operations.
4. Configure Power Platform flows and Copilot Studio topics for guided interaction.

## Build Checks

- Sensitive workload classification is present in source data
- Investigation functions authenticate correctly
- Action flows require explicit confirmation
- User-facing reports and prompts reflect current scoring state
