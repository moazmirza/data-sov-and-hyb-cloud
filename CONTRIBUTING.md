# Contributing

## Branching

- `main`: stable public content
- `dev`: integration branch
- `feature/*`: focused feature work

## Pull Request Expectations

1. Link the scenario or documentation area being updated.
2. Include sanitized examples only.
3. Update relevant docs and templates in the same change.
4. Add or update changelog entry.

## Content Quality Checklist

- Explains purpose, inputs, outputs, and dependencies
- Uses placeholders for environment-specific values
- Includes deployment or run-order notes
- Avoids screenshots with sensitive metadata
